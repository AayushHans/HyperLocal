# Romanized Hindi Examples - Complete Guide

## What is Romanized Hindi?

Romanized Hindi (also called Hinglish when mixed with English) is Hindi written using the English alphabet instead of Devanagari script. This is very common in India, especially in text messages and informal communication.

## Common Patterns

### Pattern 1: Number + Quantity + Item

```
ek kilo aata → Wheat flour - 1 kg
do liter doodh → Milk - 2 liters
teen packet namak → Salt - 3 packets
```

### Pattern 2: Item + Quantity

```
aloo ek kilo → Potatoes - 1 kg
doodh do liter → Milk - 2 liters
```

### Pattern 3: Multiple Items with "aur" (and)

```
aloo aur tamatar → Potatoes and tomatoes
chawal aur dal → Rice and lentils
```

### Pattern 4: Casual Requests

```
aloo chahiye → Potatoes
doodh lana → Milk
tamatar he → Tomatoes
```

## Tips for Customers

1. **Be Specific with Quantities**: "ek kilo" is better than just "aloo"
2. **Use Common Spellings**: Both "aloo" and "alu" work
3. **Mix Languages Freely**: "ek kilo rice" works perfectly
4. **Don't Worry About Grammar**: The system understands casual writing
5. **Use Numbers**: "2 kilo" or "do kilo" both work

## Tips for Agents

When you receive an order, it will already be translated and formatted clearly:

- All items in English
- Quantities standardized (kg, grams, liters)
- Each item on a new line
- Easy to read and fulfill

## Supported Variations

The system understands multiple spellings:

- aloo / aaloo / alu → all mean potatoes
- tamatar / tamaatar → both mean tomatoes
- kilo / kilogram → both mean kg
- liter / litre → both mean liters

## Not Supported Yet (Future)

- Regional dialects (Bhojpuri, Marwari, etc.)
- Other Indian languages (Tamil, Telugu, Bengali)
- Slang or very informal abbreviations
